## Gerar a LISTA do período — SPJ → Livros Obrigatórios (v4.0) — 10/06/2026 (1ª execução, tela capturada)

**Atalho de extração (sem depender do download):** o "Exportar planilha" dispara um GET que retorna o CSV. Endpoint (host **api**, Bearer **sem cookie**):
`GET https://api.ipe-policiacivil.sp.gov.br/cadastros/ocorrencias/boletins/pdf/listagem-bo` com query `listagemBOEnum=LIVRO_BO`, `codigoDelegacia=<cod>`, `idCircunscricao=<id ou vazio>`, `dataInicial=AAAA-MM-DD`, `dataFinal=AAAA-MM-DD`, `formato=CSV`.
- **Códigos capturados:** Aparecida = **codigoDelegacia 130201** (idCircunscricao vazio = todos). Guará-Plantão (Região do Fato Aparecida) = **codigoDelegacia 130514 + idCircunscricao 2388**.
- **CSV** é `;`-delimitado, **latin1** (acentos vêm como �). Colunas (8): `BO | Flagrante | Natureza | Vítima | Indiciado | Finalizado | Data Registro | Hora Registro`. O campo BO vem como `IS2689 - 1/2026` (nº - versão/ano).
- **Token:** o `localStorage["__tok"]` (já com prefixo "Bearer ") pode estar **defasado → 401**. Pegar o token vivo via interceptor (`setRequestHeader`/`fetch` → `window.__cap`) e **disparar o Exportar uma vez** para popular o `__cap`; aí o fetch com `credentials:'omit'` retorna 200.
- O `javascript_tool` **bloqueia** retorno com URL/`?...=` ("Cookie/query string data"): guardar o CSV em `window.__livro...` e devolver só texto ultra-limpo (status/linhas/campos por `§`).

## Ler um BO INTEIRO pela API (getPdf + pdf.js + texto dos documentos) — 10/06/2026

Pipeline validado no lote de flagrantes (IT2653, IS7882, RS6387). Host **api**, **Bearer sem cookie** (`credentials:'omit'`); token vivo em `window.__cap` (interceptor + clicar Página Inicial popula).

1. **Resolver o id:** `GET /cadastros/ocorrencias/boletins?tipoBusca=R&rdo=false&ano={AAAA}&numero={BO}&numeroInicial={BO}&page=0&size=5` → **o id está em `content[0].id`** (alias `content[0].idBo`), **NÃO** `idOcorrencia` (esse campo não existe nesta resposta — correção 10/06 no BO IT5787). Os endpoints getPdf/documentos/anexos usam esse `id`. Metadados úteis na mesma resposta: `flagrante`, `finalizado`, `medidaProtetiva` (MPU), `nomeCircunscricao`, `dataComunicacao`. **Atenção ao ANO** (RS6387 é **/2025** — buscar com ano 2025; o ano do BO ≠ ano em que reaparece no Livro).
2. **PDF consolidado + SHA-256:** `GET /cadastros/ocorrencias/boletins/getPdf/{id}` como **arrayBuffer** → `crypto.subtle.digest('SHA-256',buf)`; extrair texto com **pdf.js** (CDN cdnjs 3.11.174; `getDocument({data:buf.slice(0)})` → `getTextContent` por página). É a **fonte autoritativa** (naturezas, partes, **Auto de Apreensão com lacres/pesos**, despacho, solução, "Procedimentos Instaurados/CNJ").
3. **Lista de documentos:** `GET /cadastros/documentos/?idOcorrencia={id}&page=0&size=50`; o modelo está em `d.modelo.descricao` (ex.: AUTO DE PRISÃO EM FLAGRANTE, TERMO DE INTERROGATÓRIO, AUTO DE EXIBIÇÃO E APREENSÃO, Transcrição Automática de Oitiva).
4. **CONTEÚDO de cada documento:** `GET /cadastros/documentos/{idDoc}` → campo **`texto`** (HTML). É assim que se lê **interrogatório/oitiva/auto na íntegra** (os anexos não baixam — entrave). Decodificar entidades com `textarea.innerHTML=...; textarea.value`; limpar dígitos/hashes antes de retornar (filtro do tool). `pessoaFisica.nome` diz de quem é o termo.
5. **Anexos:** `GET /cadastros/anexos/?idOcorrencia={id}&page=0&size=80` → só **nomes** (`nomeArquivo`): LaudoPericial, LaudoIMLpessoa, FolhaAntecedentes, fotos. **O arquivo não baixa** (500/504) — registrar existência; caçar laudo/antecedentes na Segunda Via.

> Imagens sensíveis (criança/adolescente) — NUNCA abrir/descrever; só registrar (CPP 158-A; ECA). Massa do auto é **bruta**; massa líquida só no laudo IC.
